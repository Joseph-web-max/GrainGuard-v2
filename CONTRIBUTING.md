# Contributing

Contributions are welcome for documentation, accessibility, protocol compatibility, test coverage and research reproducibility.

Before contributing:

1. Keep demo, hardware, manual and laboratory evidence clearly separated.
2. Do not convert ambient RH to grain-moisture percentage.
3. Do not describe CO2 as an aflatoxin or mould detector.
4. Do not add an automatic ventilation rule without validated crop-specific EMC evidence and a documented false-safe test plan.
5. Keep V1 free of actuator control.
6. Include units, calibration assumptions, source references and limitations for new calculations.
7. Never include credentials, personal information or private field data in commits.

For scientific/model changes, submit a reproducible test dataset, baseline comparison, metrics and negative results. For sensor changes, document wiring, power requirements, calibration method and failure behaviour.
